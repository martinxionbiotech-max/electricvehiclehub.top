## 0. 方法论与诚实边界

排序四维权重（定性，不虚构搜索量）：

| 维度 | 依据来源 | 说明 |
|---|---|---|
| 数据完整度 | `quality_tier`（A 433 / B 53 / C 31） | 程序化可复现（P1 脚本），非主观 |
| 用户意图 | 买家问题信号 = 已存在的 31 篇 `*-vs-*.md` 对比 + 出口指南系列 + 技术词表被引用度 | 用「内容是否已有真实需求足迹」近似，不虚构 volume |
| 战略相关 | 品牌数据量 + 出口关注度 + 与 .net 出口情报的差异化分工 | 战略相关 = 差异化价值 + 数据支撑 |
| 编辑成本 | 每页需多少真实编辑投入才能产生差异化价值 | C 层补数据成本 > B 层去模板化 > A 层微调 |

**诚实声明**：本批**无 GSC 数据**（Search Console 未接入）。任务书第 7 类「既有获流量页」无法用真实流量校准——**不虚构 impressions/clicks/CTR**。该层单列、标注「待 GSC 接入后校准」，其余 6 层按数据完整度 + 意图 + 战略独立排序。

**总原则：不一次性重写全部页面。** 517 车型 + 72 品牌 + 86 博客 + 14 文档若一次性重写，会：(1) 引入无法逐条 review 的批量错误；(2) 产生新的同构文案（违反 P1 去模板化成果）；(3) 无法验证每批的差异化价值。改为**分批执行、每批 review 产出后再扩**。

## 1. 页面族优先级排名（高 → 低）

| 排名 | 页面族 | 数量 | 数据完整度 | 用户意图 | 战略相关 | 编辑成本 | 综合判断 |
|---|---|---|---|---|---|---|---|
| **P0** | 首页 + 主导航 | 1 + 目录/品牌目录 | 已建（P4a） | 最高（主入口） | 高 | 低（已重建） | **已完成，仅维护** |
| **P1** | 高价值完整数据车型页（A 层，出口关注度排序） | 433 | 完整（A） | 高（车型发现核心） | 高 | 低–中 | **主攻对象** |
| **P2** | 主要品牌页 | 72 | 完整 | 中高（品牌聚合） | 高 | 低（已重建 P4b） | **次优先** |
| **P3** | 真实买家问题对比 | 31 篇 `*-vs-*.md` | 完整（有来源） | 高（决策型） | 中高 | 中 | **按需扩写** |
| **P4** | 与车型关联的技术参考 | 14 文档（含 glossary） | 完整 | 中 | 中 | 中 | **按需扩写** |
| **P5** | 目的地市场 / 进口指南 | 30 市场 + 多篇指南 | 部分（税率待核） | 中高 | 中（与 .net 分工） | 高（需权威核） | **待 Phase 5 决策** |
| **P6** | 既有获流量页 | 未知 | — | — | — | — | **待 GSC 接入后校准** |

### 1.1 排名理由简述

- **P1 优先于 P2**：车型页是「发现—比较—决策」的入口节点，且 433 款 A 层数据已完整（规格/电池/动力/充电接口四字段齐全），编辑只需「差异化叙事 + 溯源深链 + 去残留」，边际价值最高。
- **P2 品牌页优先于 P3 对比**：72 品牌页已重建（P4b），且是车型页的聚合枢纽（面包屑 + 内链出口），但品牌正文多为单段有源背景，扩写空间有限、边际价值低于直接做车型。
- **P3 对比优先于 P4 技术**：对比页直击「决策型买家问题」（跨品牌/跨动力），且已有 31 篇带来源+日期的成品，扩写 = 复用既有规格比对逻辑；技术页价值偏「教育型」，转化意图弱于对比。
- **P5 市场指南靠后**：税率 `verification_status: unknown`（EUR-Lex 复核被 WAF 拦截，P1 U-7），且与 .net 姐妹站存在内容分工边界，需先做 Phase 5 landed-cost 去留决策，不宜在 .top 上继续堆市场内容。
- **P6 单独列**：无 GSC 数据时，任何「流量优先级」都是猜测，明确不排。

## 3. 执行批次建议（每批代表性页面 + 预期产出）

> 每批交付后可 review 再进下一批；批次按「代表性页面」界定范围，不逐条穷举。

### 批次 1 — Tier 1 出口旗舰深档（约 20–30 页，最高杠杆）

**范围**：§2.1 Tier 1 车型（已核验：byd-seal / byd-atto-3 / byd-dolphin / byd-han / xiaomi-su7 / xiaomi-yu7 / zeekr-001 / zeekr-7x / xpeng-g6 / xpeng-mona-m03 / mg-4 / nio-es8 / onvo-l60 / leapmotor-c10 / deepal-s07 / wuling-binguo 等）。

**每页动作**：
1. `data_source` 补完整 URL（P1 溯源缺口：517/517 仅域名提及，0 完整 URL——对确有 Wikipedia/制造商规格页的 Tier 1 逐款补深链，无条目款诚实留域名）；
2. 差异化 Summary（替换 P1 同构句残留）；
3. 四层标注（Fact/Claim/Interpretation/Estimate）应用到关键规格；
4. 内链强化（同品牌 + 同车系 + 对比 + 技术词表）。

**预期产出**：20–30 页「数据完整 + 有源 + 差异化叙事 + 内链完整」的旗舰车型页，作为整站标杆与模板范本。

### 批次 2 — 主要品牌页扩写（约 15–25 页）

**范围**：数据量前 15–25 品牌（BYD 46、Wuling 19、Changan 14、Geely Galaxy 14、Hongqi 12、Leapmotor 12、Lynk & Co 11 等）。

**每页动作**：
1. 品牌背景从「单段」扩为「有源 2–3 段」（成立史/技术路线/出口布局——**仅用可核实来源，不编造海外布局/销量**）；
2. 集团/品牌/子品牌关系表已建（P4b），补「出口定位」一句话说明（如实：仅信息平台视角）；
3. 车型卡确认无 landed-cost 残留（P4b 已剥离，抽查复核）。

**预期产出**：15–25 个高流量品牌页成为「品牌—车型—对比」枢纽，承接车型页内链回流。

### 批次 3 — 对比内容扩写（约 5–10 篇）

**范围**：Tier 1 车型间的买家决策对比（复用现有 31 篇规格比对逻辑）。

**每页动作**：同口径（价格/续航标准）、差异显式标注、来源+日期、实质差异解释——固化进 Methodology「Comparison standards」（P4c 已建）。

**预期产出**：5–10 篇决策型对比，补齐 Tier 1 车型间的高意图组合。

### 批次 4 — 技术参考深化（约 3–5 条）

**范围**：glossary + 被车型页内链引用的技术词条。

**每页动作**：四层标注逐条落地 + 权威标准引用（GB/T/IEC/UNECE 已建，P4c）+ 与具体车型关联（「哪款车用了这项技术」有据才写）。

**预期产出**：3–5 条技术词条成为「教育型」内容，承接车型页技术内链。

### 批次 5 — C/B 层补数据（约 84 页，最重、最后做）

**范围**：C 层 31 款（数据缺）+ B 层 53 款（叙事同构）。

**每页动作**：
- C 层：逐款补缺失字段（battery/motor/range/accel 等），**无源标 N/A，绝不编造**；
- B 层：去模板化 Summary，走差异化叙事。

**预期产出**：84 页从「数据待补/同构」升级为「完整 + 差异化」，但**编辑成本最高、单页杠杆最低，故排最后**。

### 批次 6 — P6 既有流量页（待 GSC 接入后校准，暂不排）

**动作**：接入 GSC → 导出真实 impressions/clicks → 按实际流量校准 P1–P5 优先级。**接入前不虚构、不预先排序。**

## 4. 「不一次性重写全部页面」原则落地

1. **批次化**：6 批，每批范围明确、可 review、可回滚。
2. **代表性先行**：批次 1 的 20–30 页 Tier 1 旗舰是「模板标杆」，review 通过后其叙事结构、溯源格式、四层标注写法复用到批次 2–5。
3. **数据驱动边界**：C 层 31 款不武断补值——无官方源即标 N/A，只升级「有源」字段；B 层 53 款只做叙事去模板化，不动已核验数据。
4. **零新增 URL**：所有批次只深化既有页面内容，不新增可索引筛选 URL / 自动对比 URL 矩阵（延续 P4c「不自动生成海量对比 URL」）。
5. **每批验证**：`npm run build` exit 0 + sitemap 700 不变 + 抽检无占位残留 + 抽检差异化叙事。
