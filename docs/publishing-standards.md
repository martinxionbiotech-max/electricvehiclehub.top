## 1. 硬门槛（四条，全部必过）

### 门槛 1 — 法规文必须有官方来源 + 日期

- 任何关税、VAT、CVD、认证、注册费、补贴、配额等**法规/费率类陈述**，必须引用**官方一手来源**（EUR-Lex、欧盟委员会、国家税务机关、海关税则、型式核准库），不得以新闻摘要、博客转述或本平台内部数据充当来源。
- 每个法规数字须带 **日期**（发布日或 accessed 日）。时点性规则（如巴西 35%、墨西哥 50%、加拿大 surtax 废止）必须标注生效/失效时点。
- 无官方来源或来源过期的法规数字：**不得作为事实发布**；可标注「待复核（UNKNOWN）」并列入整改清单。

### 门槛 2 — 对比必须统一口径

- 对比（车型对比、市场对比）只比较**可比口径**：同价格基础 / 同续航标准 / 同 trim / 同年款 / 同市场。不同口径必须显式标注差异，不得静默等同。
- 重要数字必须带来源与日期（对比页 Sources 段 + accessed 日期）。
- 不自动生成海量对比 URL；对比条目手工精选。

### 门槛 3 — 市场分析必须是独立计算或明确结论

- 市场分析（关税趋势、落地成本、补贴政策、品牌格局）必须**要么是独立计算**（可复现公式 + 输入来源），**要么是明确标注的分析判断**（第一人称立场 + reasoning），不得把「拼凑的行业常识」冒充「本平台独立结论」。
- 估算值显式标为 estimate + 依据；不得冒充报价或实测。

### 门槛 4 — 无实质增量不发布

- 新页面若相对既有页面**无实质增量**（同主题、同数字、无新来源、无新分析），**不得发布**——应合并进既有页面（见 five-02 指南去重），而非换名保留。
- 「实质增量」判据：① 新增来源/日期；② 新增可复现计算；③ 新增当地独有内容；④ 修正既有错误。四条至少占其一。

## 2. 内容分层（与 P4c 四层对齐）

| 层 | 含义 | 发布要求 |
|---|---|---|
| Fact | 可溯源至一级来源的既定事实 | 带来源 + 日期 |
| Manufacturer claim | 厂商宣称，未独立复测 | 归属厂商，不作本平台发现 |
| Editorial interpretation | 本平台分析判断 | 判断口吻 + reasoning |
| Estimate | 由文档化公式/行业基准推导 | 标 estimate + 依据 |
